# Демонстрационная база знаний

«Демо-клининг» — вымышленная компания по уборке квартир и небольших офисов. Компания, её правила и примеры созданы для демонстрации поиска по документам и проверки ответов.

Набор не связан с действующей организацией и не привязан к стране или городу. В нём нет реальных клиентов, контактов и числового прайса.

## Использование

Все пять документов образуют согласованный набор версии 1.0. Текст каждого файла представляет отдельный материал базы знаний. Произвольная замена одного документа может изменить ожидаемые ответы.

Правила описывают состав услуг. Они не содержат фактического расписания, назначений сотрудников, состояния заказов и окончательной стоимости. Помощник должен различать подтверждённые условия и сведения, которые нужно уточнить у менеджера.

Здесь приведены демонстрационные операционные правила, а не договор или инструкция по самостоятельной очистке поверхностей.
