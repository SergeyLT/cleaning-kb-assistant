# Конфигурация

[.env.example](../.env.example) перечисляет поддерживаемые поля без секретов. Для запуска используйте `init-env`, а не пустые значения примера. Переменные окружения имеют приоритет над `.env`. Не публикуйте настройки и полный вывод `docker compose config`: он содержит подставленные секреты.

| Переменная | Назначение |
|---|---|
| `APP_ENVIRONMENT` | `local`, `test` или `production` |
| `APP_VERSION` | Версия; образ получает её при сборке |
| `APP_BASE_URL` | В .env — `http://127.0.0.1:8001`; в production требуется HTTPS |
| `HOST_PORT` | Локальный порт Compose, по умолчанию `8001` |
| `ADMIN_USERNAME`, `ADMIN_PASSWORD_HASH` | Логин и хеш пароля из `init-env` |
| `API_KEY` | Отдельный случайный ключ, обязательный |
| `SESSION_TTL_SECONDS` | Срок сессии, по умолчанию `28800` секунд |
| `LOGIN_ATTEMPTS_PER_MINUTE` | Лимит входов, по умолчанию `10` |
| `MAX_REQUEST_BYTES` | Предел HTTP-тела, по умолчанию `1048576` байт |
| `DATABASE_PATH` | Локально `output/cleaning-kb.sqlite3`, в Compose `/data/cleaning-kb.sqlite3` |
| `QDRANT_URL` | Для Python-запуска `http://127.0.0.1:6333`; Compose задаёт внутренний адрес |
| `QDRANT_API_KEY` | Необязательный ключ отдельного Qdrant; локальный Compose его не использует |
| `DEPENDENCY_TIMEOUT_SECONDS` | Таймаут проверки Qdrant, по умолчанию `2` секунды |
| `PROXYAPI_KEY` | Секретный ключ модели; не совпадает с `API_KEY` приложения |
| `PROXYAPI_BASE_URL` | Поддерживаемый адрес `https://api.proxyapi.ru/v1` |
| `GENERATION_MODEL` | По умолчанию `openai/gpt-4.1-mini`; требуется поддержка строгого JSON |
| `EMBEDDING_MODEL`, `EMBEDDING_DIMENSION` | По умолчанию `openai/text-embedding-3-small`, `1536` |
| `PROVIDER_TIMEOUT_SECONDS` | Таймаут сетевой операции модели, по умолчанию `45` секунд |
| `PROVIDER_CALLS_PER_MINUTE`, `PROVIDER_CALLS_PER_DAY` | Сохраняемые общие лимиты, по умолчанию `20` и `200` |
| `PROVIDER_TOKEN_BUDGET_PER_DAY` | Консервативный бюджет резерва, по умолчанию `500000` |
| `MAX_ANSWER_TOKENS` | Предел генерации, по умолчанию `1600` |
| `MAX_DOCUMENT_CHARS`, `MAX_CONTEXT_CHARS` | По умолчанию `30000` и `14000` символов |
| `RETRIEVAL_TOP_K`, `RETRIEVAL_MIN_SCORE` | По умолчанию `8` фрагментов и cosine-порог `0.2` |
| `CONFIDENCE_THRESHOLD` | Внутренний числовой порог review и категории low, по умолчанию `0.7`; публичный confidence — high/medium/low |
| `DIALOG_MAX_TOKENS` | Полная история с источниками и резервом следующего ответа; по умолчанию `16000`, допустимо 2000–40000 |
| `SUMMARY_MAX_TOKENS` | Отдельный предел генерации итога, по умолчанию `2400` |

Вопрос ограничен 2000 символами, число документов MVP — 1000, одновременно выполняются до двух операций ответа/индексации. Индексация документов последовательная. Лимиты платного API общие для учётной записи приложения и сохраняются после рестарта. Суточные лимиты сбрасываются по UTC. Резерв считается по UTF-8-байтам запроса и пределу ответа: это верхняя оценка токенов, не денежная сумма и не фактический usage. Неудачные/прерванные вызовы тоже занимают резерв, поскольку списание могло произойти. Денежный предел дополнительно настройте в кабинете провайдера.


В Compose передаются поля из его `environment`. Для отдельного защищённого Qdrant адаптируйте Compose: `QDRANT_API_KEY` не передаётся локальному контейнеру автоматически. Runtime-параметры production и тег образа описаны в [руководстве развёртывания](deployment.md).
